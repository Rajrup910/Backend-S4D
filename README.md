# Multimodal & Cross-Paradigmatic Ensembling for Safe Skin Lesion Classification Across Dermoscopic and Clinical Domains

A self-contained, publication-grade research workspace investigating classification performance, ensemble diversity, uncertainty calibration, multimodal clinical fusion, and cross-domain generalization in automated dermatology.

Target Publication Venues: *IEEE Transactions on Medical Imaging (TMI)* / *Medical Image Analysis (MedIA)* / *MICCAI* / *Lancet Digital Health*.

---

## 1. Research Motivation & Core Contributions

1. **Combating Majority Class Bias ("Mole Guessing")**: In the HAM10000 benchmark, `nv` (melanocytic nevus) constitutes ~67% of cases. A naive predictor guessing "mole" every time scores ~67% accuracy while missing 100% of melanomas. We enforce **Macro-F1, Balanced Accuracy, and Escalation Sensitivity** as the primary headline metrics under strict **lesion-grouped splitting** (`assert_no_leakage`) to prevent cross-split patient contamination.
2. **Cross-Paradigmatic Inductive Ensembling**: Combining architectures with fundamentally distinct inductive biases (Hierarchical CNNs, Dense Connection Networks, Modern ConvNeXts, and Vision Transformers) using leak-free Out-of-Fold (OOF) stacking, Dirichlet logit calibration, and Caruana greedy selection.
3. **Bridging the "Dermoscopy-to-Smartphone" Reality Gap**: Establishing empirical benchmarks for the severe domain shift between clean epiluminescence dermoscopy (HAM10000, 7 classes) and raw clinical smartphone photography (PAD-UFES-20, 6 classes). We demonstrate that direct cross-domain evaluation yields near-total melanoma recall collapse (0.00), but hierarchical warm-start fine-tuning recovers melanoma recall to **0.625** and escalation sensitivity to **0.975**.
4. **Clinical Decision Utility & Selective Prediction**: Incorporating cost-sensitive asymmetric risk thresholding (penalizing false-negative malignancies), Decision Curve Analysis (DCA), and uncertainty-guided selective abstention (deferring ambiguous or out-of-distribution cases to human dermatologist review).
5. **Distribution-Free Guarantees & Reproducibility**: Wrapping predictions in **conformal prediction sets** (split/APS with class-conditional Mondrian calibration) for finite-sample coverage guarantees, and enforcing a leak-free, single-test-read protocol in which every reported table and figure is regenerated by a script from `results/` — no hand-entered numbers.

> Method detail for all five contributions, including the second-layer techniques that target each accuracy bottleneck (E1–E6), is in [RESEARCH_ROADMAP.md](RESEARCH_ROADMAP.md) §2A.

## 5. Research Methodology & Execution

See [RESEARCH_ROADMAP.md](RESEARCH_ROADMAP.md) for the detailed 6-phase scientific campaign:

- **Phase 0**: Baseline reproduction, metric unification, and Shades of Grey color constancy standardization.
- **Phase 1**: Out-of-fold (OOF) ensembling across the six frozen backbones (soft-vote, rank average, Nelder-Mead simplex optimization, non-negative stacking, and Caruana greedy search).
- **Phase 2**: Multi-scale TTA, Dirichlet calibration, cost-sensitive asymmetric risk thresholding, and Decision Curve Analysis (DCA).
- **Phase 3**: Retraining with Vision Transformers (Swin-V2 / MaxViT), LDAM-DRW margin loss, and tabular patient metadata fusion (`age`, `sex`, `anatomical_site`).
- **Phase 4**: Cross-domain generalization (HAM10000 $\leftrightarrow$ PAD-UFES-20), Fitzpatrick skin-tone fairness audit, and selective prediction (uncertainty abstention).
- **Phase 5**: Full ablation synthesis, 1,000-sample bootstrap 95% CIs, McNemar/DeLong statistical tests, and publication manuscript packaging.

## 6. How to Run

Environment: Python 3.12, PyTorch 2.11+cu128, torchvision 0.26, scikit-learn 1.5+.
Interpreter: `C:\Users\RAJ\Downloads\Capstone\.venv\Scripts\python.exe`.

```bash
# 1. Verify CUDA kernel and environment integrity
python scripts/verify_env.py

# 2. Evaluate single model baseline on held-out test split
python -m ml.evaluation.evaluate --checkpoint ml/checkpoints/convnext_tiny_best.HAM-only.pt --split test

# 3. Generate aligned predictions for all 6 models across val and test splits
python -m research.ensembling.generate_predictions

# 4. Run the ensembling suite and log results
python -m research.ensembling.run_ensembles --split test

# 5. Execute Decision Curve Analysis & cost-sensitive thresholding
python -m research.dca.evaluate_dca
```

All metrics flow through `ml/evaluation/metrics.py::compute_metrics` so that individual models and composite ensembles are evaluated via an identical, leak-free pipeline.
